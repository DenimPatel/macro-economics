## 📞 Quick Help

| Problem | Solution |
|---------|----------|
| npm install fails | Check Node.js: `node -v` (need 16+) |
| Dev server won't start | Clear cache: `rm -rf node_modules` then reinstall |
| Build errors | Run `npm run lint` to see TypeScript issues |
| Chart not showing | Check console for errors: F12 → Console tab |
| Want to add new tool | Copy MultiplicerSimulator.tsx pattern |
| Want to add formula | Edit src/utils/calculations.ts |
| Want to deploy | Run `npm run build` then `vercel deploy` |
