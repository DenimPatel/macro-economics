# Project docs

Historical and implementation notes from building the course site. These are
records, not living documentation — the source of truth for how the project is
organised is the root [README.md](../README.md) and [AGENTS.md](../AGENTS.md).

- `PROJECT_STATUS.md`, `PHASE_0_COMPLETE.md`, `NEXT_PHASE.md` — build-out history.
- `IMPLEMENTATION.md`, `TOOLS_IMPLEMENTED.md`, `PHILLIPS_CURVE_IMPLEMENTATION.md` —
  implementation notes for the interactive tools.
- `IS-LM-EXPLAINED.md`, `IS-LM-EXPLORER-SUMMARY.md` — model explanations.
- `GETTING_STARTED.md`, `LAUNCH.md`, `SUMMARY.md`, `SUBAGENT_COMMANDS.md` —
  earlier onboarding material, superseded by the root README and CONTRIBUTING.

When updating the project, prefer editing the root README, CONTRIBUTING.md, or
AGENTS.md over adding another document here.
